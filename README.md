# SCALAR (1)

> A minimalist, technical unit converter for Android inspired by the Nothing OS aesthetic and dot-matrix typography.

---

## Overview

SCALAR is a lightweight, distraction-free Android unit converter designed for quick, one-handed utility. Built with high-contrast monochrome surfaces and dot-matrix styling, it provides instant, offline conversions across daily engineering, laboratory, and travel units.

---

## Features

- **7 Measurement Categories:** Accurate conversions across Length, Weight/Mass, Temperature, Volume, Area, Speed, and Time.
- **Nothing OS Typography:** Native dot-matrix numerals and labels powered by `NDot 57`.
- **Ergonomic Controls:** Single-tap "AC" (All Clear) button to reset calculations instantly.
- **Smart Keyboard Behavior:** Auto-dismisses the soft keyboard and computes values on input completion (`actionDone`).
- **Adaptive Insets:** Edge-to-edge layout calibrated to avoid overlapping notches, camera cutouts, and gesture bars.
- **Portrait-Locked UI:** Optimized strictly for handheld vertical use.

---

## Tech Stack

- **Language:** Java
- **UI Framework:** Android Material Components (Material 3)
- **Minimum SDK:** Android 7.0 (API 24)
- **Target SDK:** Android 14+ (API 34)
- **Build System:** Gradle (Kotlin DSL)
